# Frontend

The frontend is a dependency-free static ES module app served by the cross-platform dev controller. It uses no bundler, so a normal static server is enough for development and deployment.

## Structure

```text
frontend/
  index.html            User audit workspace
  admin.html            Administrator workspace
  assets/
    core.js             Shared HTTP, token, URL, and escaping helpers
    app.js              Authentication and audit workflow
    admin.js            User and task administration
    styles.css          Responsive design system and page styles
    runtime-config.js   Generated runtime API configuration
```

Default pages:

- App: `http://127.0.0.1:3000`
- Admin: `http://127.0.0.1:3000/admin.html`

Start or stop the full stack from the repository root:

```bash
python dev.py start
python dev.py stop
```

The frontend reads `frontend/assets/runtime-config.js`, which is generated by `dev.py` from `.env`.

## Checks

Run the dependency-free contract and syntax checks:

```bash
python scripts/check_frontend.py
```

When Chrome or Edge is installed, run the real-browser registration slider and layout smoke test:

```bash
node scripts/test_register_slider.js --url=http://127.0.0.1:3000 --browser=chrome
```

The UI keeps its API integration behind `assets/core.js`. New pages should reuse `createJsonClient`, `escapeHtml`, and `appendAccessToken` rather than implementing their own request or rendering helpers.
